# 🤖 BubbleChat AI

An elegant AI chatbot application built with Flutter using Riverpod state management, DashChat UI, and OpenRouter API integration.

## ✨ Features

- 💬 Real-time AI chat
- ⚡ Fast OpenRouter API integration
- 🧠 GPT-powered responses
- 🎨 Modern dark UI
- 📝 Markdown rendering support
- 🔄 Typing indicator
- 📱 Responsive mobile design
- 🧩 Riverpod state management
- 💭 Smooth chat experience using DashChat

---

### Frontend

## 🚀 Getting Started

### 1️⃣ Clone Repository

```bash
git clone https://github.com/yourusername/bubblechat-ai.git
```

---

### 2️⃣ Install Packages

```bash
flutter pub get
```

---

### 3️⃣ Create `.env`

```env
API_KEY=your_openrouter_api_key
URL=https://openrouter.ai/api/v1/chat/completions
```

---

### 4️⃣ Run App

```bash
flutter run
```
